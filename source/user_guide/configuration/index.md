# Concepts and Configuration

Where Getting Started shows what a program looks like, this section explains why. Its throughline is the two-phase model at the heart of the API: *describe* a scene, then *build* it once and *step* it. Almost every configuration choice belongs to the describe phase, and `build()` freezes it. Read it to understand the object model and to set backends, options, conventions, and saved state deliberately.
