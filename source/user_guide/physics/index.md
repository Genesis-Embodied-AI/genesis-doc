# Physical Entities

Choose a body type to learn how to create it and set its physical properties:

- {doc}`Rigid bodies <rigid_bodies>`: single bodies and articulated robots, their physical properties, and specialized rigid entities.
- {doc}`Deformables and fluids <beyond_rigid_bodies>`: choose a material and solver, then add muscle actuation or combine rigid and soft parts.

{doc}`Particle emitters <emitters>` create particles during a run. {doc}`Force fields <force_fields>` apply forces over space, and {doc}`Coupling <coupling/index>` configures interactions between different solvers. For the underlying physics and algorithms, see {doc}`Theory and Modeling </user_guide/theory/index>`.
