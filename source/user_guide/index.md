# User Guide

This guide takes you from installation through the core concepts and tutorials for Genesis World. If you are new, start with the  {doc}`Overview <overview/index>`.  Then run the [Hello, Genesis World](http://localhost:8766/user_guide/getting_started/hello_genesis.html) tutorial. After that, go to the section that matches what you are building.

Each section below opens with a landing page that frames the topic and points to its pages. Expand a section in the sidebar to jump straight to one.
