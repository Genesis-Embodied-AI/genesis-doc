# Surface

A surface holds the visual information the renderer uses for an entity, or for its individual links and geoms. Which texture channels a surface carries depends on its type, and every channel takes a {doc}`gs.textures.Texture </api_reference/engine/entity/texture/index>` object. For which surface properties render under each backend, see {doc}`/user_guide/rendering/surfaces_textures`.
