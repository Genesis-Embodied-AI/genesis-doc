# ToolEntity

A `ToolEntity` is a kinematically scripted collider created from a {py:class}`gs.materials.Tool <genesis.engine.materials.tool.Tool>` material. It carries no dynamics of its own, so drive its motion directly; it couples one-way with soft and particle-based media to push, stir, or deform them.
