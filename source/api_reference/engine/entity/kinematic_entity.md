# KinematicEntity

A `KinematicEntity` is an articulated body that the kinematic solver moves without dynamics, such as a ghost robot showing a reference motion. Create one with the `gs.materials.Kinematic` material or the `gs.entities.Kinematic` spec. {py:class}`RigidEntity <genesis.engine.entities.rigid_entity.rigid_entity.RigidEntity>` derives from it, so the kinematic methods below also apply to rigid entities.
